02 / BUILT TO CONNECT

Your model.
More possibilities.

Start with the derive. Add the boundaries your application needs.

parse.rs 
use rydantic::Model;

#[derive(Debug, Model)]
struct User {
    #[model(trim, min_length = 2)]
    name: String,
    #[model(coerce, ge = 18)]
    age: u8,
}

let user = User::parse_json(
    r#"{"name":" Alice ","age":"25"}"#,
)?;
assert_eq!(user.name, "Alice");
assert_eq!(user.age, 25);

Strict types. Explicit coercion. Normalization at the boundary.
