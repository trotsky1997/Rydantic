## Start with a complete example

The [HTTP + database guide](/integrations/http-database) connects a validated Axum endpoint to the same SQL model. Start with SQLite locally, then choose an independent PostgreSQL or MySQL driver.

```sh
cargo run -p rydantic --example database_api --features axum,sqlite -- --smoke
```

## Add only the features you need

| Application boundary | Cargo feature | Continue with |
| --- | --- | --- |
| JSON-RPC 2.0 (unreleased source only) | `jsonrpc` | [Typed methods](/integrations/jsonrpc) |
| HTTP requests and responses | `axum` | [Axum and Tokio](/integrations/axum) |
| Local database | `sqlite` | [Database models](/integrations/sql) |
| Server database | `postgres` or `mysql` | [PostgreSQL and MySQL](/integrations/databases) |
| Native binary messages | `capnp` | [Generated bindings](/integrations/capnp) |
| Existing binary schema | `capnp` | [External schema bindings](/integrations/existing-capnp) |

See [Cargo features](/reference/features) for combinations and [release notes](/reference/releases) for version details. For typed agents, structured output or model routing, start with the separate [RydanticAI crate](/integrations/ai).
