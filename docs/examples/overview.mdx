## Run from the source checkout

```sh
git clone https://github.com/trotsky1997/Rydantic.git
cd Rydantic
cargo run --locked -p rydantic --example data_contract
cargo run --locked -p rydantic-ai --no-default-features --example typed_agent
```

Use the source revision that matches these docs. Examples added in a pull request preview become available on `main` after merge. The project is tested with Rust **1.98.1**.

## Choose your environment

| Prerequisite | Examples |
| --- | --- |
| Rust and Cargo only | Core models, async checks, offline agents, structured streams and graphs |
| Bundled SQLite | Local HTTP APIs and migration examples |
| Cap’n Proto compiler | `auto_capnp` and generated Rust bindings |
| A local test database | PostgreSQL/MySQL driver examples |
| Configured model API | Live providers, image and PDF examples |

The offline AI recipes use deterministic demonstration responses. Live recipes use `BASEURL`, `MODEL` and optional `APIKEY`; the Jev recipe requires both `TYPESAFE_BASEURL` and `TYPESAFE_APIKEY`. Keep credentials in your local environment.
