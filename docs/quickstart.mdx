Parse a JSON document, normalize its fields and return a validated Rust value. This is the starting point for every integration.

## Choose your version

<Note>
These examples target **Rydantic 0.8.0 stable**. Review the [release notes](/reference/releases) for the breaking Context unwind-boundary change from 0.7.x and the explicit-derive contract from 0.6.0. For older deployments, use the [0.6.0 tagged guide](https://github.com/trotsky1997/Rydantic/tree/v0.6.0).
</Note>

## Add the dependency

```toml Cargo.toml
[dependencies]
rydantic = "=0.8.0"
```

## Define your first model

```rust src/main.rs
use rydantic::{Model, SchemaMode};

#[derive(Debug, Model)]
#[model(extra = "forbid")]
struct User {
    #[model(trim, min_length = 3, max_length = 30)]
    name: String,

    #[model(coerce, ge = 18, le = 120)]
    age: u8,

    #[model(trim, lowercase, email)]
    email: String,

    #[model(default)]
    tags: Vec<String>,

    note: Option<String>,
}

fn main() -> Result<(), rydantic::ValidationErrors> {
    let user = User::parse_json(
        r#"{"name":" Alice ","age":"25","email":" ALICE@EXAMPLE.COM "}"#,
    )?;

    assert_eq!(user.name, "Alice");
    assert_eq!(user.age, 25);
    assert_eq!(user.email, "alice@example.com");
    println!("{}", user.dump_json()?);

    let schema = User::json_schema(SchemaMode::Output);
    assert!(schema.is_object());
    Ok(())
}
```

`Model` also generates Serde's `Serialize` and `Deserialize` implementations. Derive `Model` once per model. Deserialization runs full validation, and serialization revalidates the current object.

## Run an example

From the source checkout, run the model or tool-call examples:

```sh
cargo run -p rydantic --example user
cargo run -p rydantic --example tool_call
cargo run -p rydantic --example tool_call -- --schema
cargo run -p rydantic --example tool_call -- '{"kind":"ping"}'
```
