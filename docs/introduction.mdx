Rydantic brings Pydantic-style data modeling to Rust. Define a model once, then use it to parse JSON, normalize values, collect validation errors, generate JSON Schema, work with native Cap’n Proto messages, serve HTTP requests and persist validated database rows.

## The model is the contract

```rust
use rydantic::Model;

#[derive(Debug, Model)]
struct User {
    #[model(trim, min_length = 2)]
    name: String,
    #[model(coerce, ge = 18)]
    age: u8,
}

let user = User::parse_json(r#"{"name":" Alice ","age":"25"}"#)?;
assert_eq!(user.name, "Alice");
assert_eq!(user.age, 25);
```

Parsing is strict by default. Enable coercion per field, make normalization explicit and receive structured errors with field paths. Native JSON parsing reads field slices directly; it does not construct a full JSON value tree before decoding a typed model.

## Choose the pieces you need

The default dependency includes the model derive. HTTP, SQL drivers, Cap’n Proto, dates, decimals and runtime JSON Schema validation are optional features. PostgreSQL and MySQL can each be enabled without SQLite.
