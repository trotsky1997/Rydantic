The default feature is `derive`. Every integration below is opt-in.

| Feature | Provides |
| --- | --- |
| `derive` | `Model`, `SqlModel` and protocol generation macros |
| `partial-json` | Bounded [partial JSON snapshots](/models/partial-json), not business-validated models |
| `settings` | Explicit ordered [settings sources](/models/settings) with Model validation and redacted source errors |
| `dynamic` | Runtime JSON Schema validation with `DynamicModel` |
| `chrono` | `chrono` date and time support |
| `decimal` | `rust_decimal` support |
| `phone` | Unreleased source-only [canonical E.164 phone type](/domain-types), not available in beta.3 |
| `country` | Unreleased source-only [ISO 3166-1 code types](/domain-types), not available in beta.3 |
| `currency` | Unreleased source-only [known currency catalog codes](/domain-types), not available in beta.3 |
| `capnp` | Native and packed Cap’n Proto serialization |
| `axum` | Axum 0.8 extractors, responses and structured rejections |
| `sqlx` | Shared SQL metadata and API, with no database driver |
| `sqlite` | SQL integration and bundled SQLite |
| `postgres` | SQL integration, PostgreSQL and Rustls TLS |
| `mysql` | SQL integration, MySQL RSA authentication and Rustls TLS |

## Example configurations

<CodeGroup>
```toml JSON only
rydantic = "=0.7.0-beta.3"
```
```toml HTTP + PostgreSQL
rydantic = { version = "=0.7.0-beta.3", features = ["axum", "postgres"] }
tokio = { version = "1", features = ["macros", "rt-multi-thread", "net"] }
```
```toml Binary protocol
rydantic = { version = "=0.7.0-beta.3", features = ["capnp"] }
```
</CodeGroup>

Automatic Cap’n Proto binding generation requires the official `capnp` compiler on `PATH`. Use Rust 1.98.1 to match the toolchain tested by this repository.

## API reference

The [stable 0.6.0 Rust API documentation](https://docs.rs/rydantic/0.6.0/rydantic/) lists runtime traits and methods. The [source manifest](https://github.com/trotsky1997/Rydantic/blob/main/crates/rydantic/Cargo.toml) contains the complete dependency and feature definitions.
