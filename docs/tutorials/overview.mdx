## Before you start

You need Rust and Cargo. Familiarity with structs, `Result` and basic `async` Rust is enough. The repository is tested with Rust **1.98.1**. SQLite is bundled; the default tutorial path needs no database service or API credentials.

For the complete runnable examples, start from the repository revision matching these docs:

```sh
git clone https://github.com/trotsky1997/Rydantic.git
cd Rydantic
cargo run --locked -p rydantic --example data_contract
```

<Note>
These tutorials target Rydantic **0.7.0-beta.4** and RydanticAI **0.6.0**. A pull request preview can include examples that reach the default branch when merged. Use that pull request's source checkout when following a preview.
</Note>

The first-model and typed-agent tutorials also include standalone `Cargo.toml` files. Copy their complete source into `src/main.rs` to run outside the workspace.
